# Library-on-go

Консольная система управления библиотекой, написанная на Go.

## Возможности

- **Авторизация и регистрация** — создание учётной записи и вход в систему по email/паролю с подтверждением по коду аутентификации
- **Управление публикациями** — поддержка трёх типов изданий:
  - **Книги** — автор, ISBN, жанр, серия и др.
  - **Комиксы** — номер выпуска, сценаристы, художники, возрастной рейтинг и др.
  - **Газеты** — редакция, тема, ISSN, тираж, рубрики и др.
- **Система полок** — типобезопасные полки на дженериках Go, вмещающие до 5 элементов каждая
- **Консольный интерфейс** — текстовое меню для взаимодействия

## Модель данных

### BasePublication

Базовая структура для всех типов публикаций:

| Поле             | Тип      | Описание                          |
| ---------------- | -------- | --------------------------------- |
| `id`             | `string` | Уникальный идентификатор          |
| `title`          | `string` | Название                          |
| `publisher`      | `string` | Издатель                          |
| `publicationDate`| `string` | Дата публикации                   |
| `language`       | `string` | Язык                              |
| `pageCount`      | `int`    | Количество страниц                |
| `format`         | `string` | Формат (hardcover/softcover/...)  |

### Shelf[T]

Дженерик-полка с максимальной вместимостью 5 элементов. Поддерживаемые типы: `Book`, `Comics`, `Newspaper`.

Методы:
- `Add(item T) error` — добавить элемент
- `Count() int` — количество элементов
- `IsFull() bool` — проверка заполненности

## Использование

```bash
go run main.go
```

При запуске программа предложит:
1. **Зарегистрироваться** — ввести имя, возраст, пол, email и пароль. Система сгенерирует код аутентификации.
2. **Войти** — ввести email и пароль, затем подтвердить кодом аутентификации.

После успешного входа отображаются 5 демо-полок с книгами, комиксами и газетами.

## Зависимости

Только стандартная библиотека Go (криптография, JSON, файловая система). Сторонних зависимостей нет.

## Системные требования

- Go 1.26 или выше
- ОС: Windows, Linux, macOS
